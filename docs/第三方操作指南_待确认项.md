## 6. 已发现的文档/界面不一致

1. 当前 UI 的 `授权测试` 名称容易被理解为正式授权，但实现是固定测试参数的授权请求，已在主指南标记为高风险。
2. 当前 UI 的“启动服务”启动的是 Proxy 本地监听和业务服务，不是 Windows 服务管理器中的系统服务。
3. 当前 UI 显示六类预览资源，但当前默认配置未配置三路车牌摄像头，车牌预览默认可能返回 `plate_preview_not_configured`。
4. 仓库旧 README 的端口和 Proxy 位数说明与当前 Proxy 配置/近期进度记录不一致，必须以正式交付包确认。
5. 源码中仍保留按资源拆分的预览按钮变量和处理函数，但当前实际界面通过一个下拉框和统一“开始预览/停止预览”操作，按钮清单按实际可见界面记录。
