## 6. 不应当列为当前可见功能的项目

- 当前 Proxy UI 没有可见的证件信息输入框，也没有可编辑授权字段。
- 当前 Proxy UI 没有闸机开、闸机关、放行或通行控制按钮。
- 当前默认配置没有三路车牌摄像头地址，车牌预览不能按“界面可见”直接等同于“默认可用”。
- 原生 DLL 的导出函数、C# 直连 Demo 的输入框和 Delphi Demo 的窗口不属于本 Proxy 主界面，不能混入操作员按钮清单。
