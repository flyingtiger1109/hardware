# 五合一车道硬件平台功能边界清单

## 1. 支持

以下内容由当前 Proxy 代码、界面和配置直接支持：

- 启动和停止本地 Proxy 服务；
- 单实例运行和托盘最小化；
- 显示 DLL 监听、终端回调监听、当前终端和运行指标；
- 在终端 1/左通道与终端 2/右通道之间切换；
- 开始和结束当前终端业务流程；
- 发起人脸抓拍、指纹抓拍、虹膜抓拍；
- 发起 OCR 证件识别和 IC/NFC 卡识别；
- 接收异步回调并在日志显示请求结果；
- 保存人脸、指纹、虹膜图片及 OCR 结果文件；
- 保存 OCR 证据图片（可见光、红外光、紫外光和人像，取决于终端返回内容）；
- 启动/停止摄像头、指纹和虹膜预览；
- 按配置启用三路车牌预览：出境车牌、入境车牌 2、入境车牌 3；
- 自动和手工执行终端硬件健康检测；
- 显示、过滤、清空 UI 日志并导出当前 UI 日志。

## 2. 有限支持

| 内容 | 当前限制 |
| --- | --- |
| 车牌预览 | 界面提供三路资源，但当前仓库的 Proxy 配置未写入 `preview.plate.cj/rj2/rj3`，默认可能返回 `plate_preview_not_configured`；需现场配置并验证 |
| 授权 | 当前界面按钮名为“授权测试”，使用固定测试参数；是否可连接生产终端、最终授权字段和业务规则需项目负责人确认 |
| 终端切换 | 支持两个配置终端，切换时有请求保护和预览恢复逻辑；业务执行中切换可能影响排队任务和旧回调，不作为推荐操作 |
| 健康检测 | 支持状态展示和自动重试，但健康状态只反映终端上报，不等同于采集成功或人员通行安全 |
| 识别结果 | OCR、IC 卡、虹膜依赖终端异步回调；请求已受理不等于最终成功 |
| 文件保存 | 默认按程序目录、日期、请求编号保存；具体现场保留期限、备份和删除策略待确认 |
| 运行架构 | Proxy、原生 DLL、C# Demo、Delphi Demo 分属不同运行角色；正式交付版本、位数和启动顺序待确认 |
| 预览兼容性 | 代码有 VLC/MJPEG/RTSP 兼容路径，但目标现场的设备流、外部窗口句柄、DPI 和长时间预览仍需人工验证 |

## 3. 不支持

- 当前 Proxy 界面不提供修改终端硬件内部参数的功能；
- 不提供修复摄像头、读卡器、指纹、虹膜等物理硬件故障的功能；
- 不提供修改第三方业务数据库或人工改写识别结果的功能；
- 不提供未经定义的第三方协议适配；
- 不提供闸机开关、放行、通行方向控制或安全联锁控制；
- 不保证在网络中断、终端离线、设备忙或终端超时情况下完成请求；
- 不提供操作员角色登录、权限分级或审计授权管理；
- 不提供在 Proxy UI 中手工输入和编辑正式授权人员信息的功能；
- 不提供把 UI 日志“清空”同步为删除磁盘日志的功能；
- 不提供把导出日志自动脱敏的功能。

## 4. 禁止操作

- 禁止重复启动多个 Proxy 实例；
- 禁止在业务、识别、抓拍或预览进行中切换终端；
- 禁止在等待异步回调时连续重复点击 OCR、IC 卡、虹膜或授权按钮；
- 禁止在设备显示“启动中、离线、异常、待检测”时强行连续发起对应业务；
- 禁止在预览运行时销毁、重建或关闭预览承载窗口；
- 禁止直接结束进程作为正常退出方式；
- 禁止运行中手工修改配置文件、DLL、Proxy、VLC 或核心依赖；
- 禁止手工修改 OCR JSON、MRZ JSON、授权回调或其他结果文件来改变业务结论；
- 禁止断开网络、关闭终端电源或拔出设备来“中断”正在执行的请求；
- 禁止把“授权测试”当作正式授权操作使用；
- 禁止把包含完整证件号、姓名、卡号、Token、密码或内部地址的日志发送给无关人员；
- 禁止绕过第三方程序、DLL 和 Proxy 的正常调用链路直接调用未公开中间接口。

## 5. 操作人员与技术维护人员边界

| 事项 | 操作人员可做 | 技术维护人员处理 |
| --- | --- | --- |
| 服务 | 启动/停止服务，查看状态和日志 | 修改监听端口、修复端口冲突、调整部署 |
| 终端 | 按流程切换左/右通道 | 修改终端地址、网段、回调地址和防火墙 |
| 预览 | 选择资源、开始/停止预览 | 检查 VLC、RTSP/MJPEG、窗口句柄和播放器日志 |
| 采集/识别 | 按现场要求发起一次请求并确认结果 | 分析协议、回调、超时、队列和终端接口 |
| 文件 | 查看授权范围内的结果并反馈文件名 | 处理权限、路径、磁盘、备份和数据恢复 |
| 日志 | 查看、清空 UI 显示、导出并脱敏 | 保留原始日志、分析堆栈、调整日志配置 |
| 配置/程序 | 不直接修改 | 由维护人员备份、修改、验证和回退 |
| 设备故障 | 检查电源、线缆、网络指示并停止操作 | 进行设备维护、服务重启、替换和现场联调 |
